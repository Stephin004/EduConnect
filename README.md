# EduConnect

A responsive multi-page educational website.

## Run

```bash
cd EduConnect1
npm install
npm start
```

Then open:
- http://localhost:3000

## API
- `GET /api/health`
- `GET /api/courses`
- `GET /api/mentors`
- `POST /api/register`

Registrations are saved to:
- `data/registrations.json`
